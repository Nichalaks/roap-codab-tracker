Next review = the later of last review and last update, plus the dataset's update frequency (1 year for most datasets, 2 for some). This follows the 12-month review cycle in the IM Toolbox and matches the "Next review" column on the FIS dashboard. Scope. "ROAP-tagged" uses the dashboard's Regional office field. "All RFM" adds the other countries in the Regional Focus Model (set in config.json) that the dashboard leaves untagged, such as Afghanistan, Pakistan and the Pacific islands. Data flow. A GitHub Action copies the FIS dashboard's CSV files into this repository every day after FIS updates them (06:00 UTC). The page reads that copy. "Refresh from FIS" reads the FIS files directly, for when you need changes made since the last daily sync.
